# Hand Gesture Drawing

Draw on the screen using hand gestures through your webcam. No mouse or touch needed.

## Features
- 1 finger: draw
- 2 fingers: select a color
- Open palm: erase
- Color palette: Red, Orange, Yellow, Green, Blue, Purple
- Eraser, clear, save and record options

## Keys
- r: start/stop recording
- s: save drawing
- q: quit

## Built With
- Python
- OpenCV (webcam and drawing)
- MediaPipe (hand and fingertip tracking)
- NumPy (canvas)

## How to Run
1. Install Python 3.12
2. Install libraries:
   pip install opencv-python mediapipe numpy
3. Run:
   python hand_draw.py

The hand model file downloads automatically on first run.
